# Eden's Purr - Online Arena

## Setup
1. Install Node.js.
2. Run: npm.cmd install
3. Run: npm.cmd run verify-files
4. Run: npm.cmd test
5. Run: npm.cmd start
6. Open http://localhost:3000

## Important
Keep the original game backup in the backups folder.
Do not share your .env file or publish its secrets.
Premium outfit payments remain disabled until secure payment verification is configured.
This project has not yet been fully verified in a browser or production environment.
